# Archive: Align v1

These pages describe Align v1, the one-day SpeedHacks prototype (October 2026) and its follow-ups: the Northstar
demo store, custom `w_` workspaces with shared role passcodes, the proposal flow, repo-local capture and wake-ups,
the Sparta sandbox runs and the Alike retrieval demo. v1 was retired on 2026-10-30; the code they describe is gone
from this tree, and their commands, routes and file paths no longer work here.

They are kept as a record only. The current product is described in `../../README.md`, `../HOSTING.md`, `../MCP.md`,
`../v2/WIRE.md` and the specification in `specs/align/` at the repository root.

| Page | What it recorded |
| --- | --- |
| `README-v1.md` | The prototype's README: the Northstar scenario, the Sparta results and the judging notes |
| `DEMO_SCRIPT.md` | The live demo script for the Northstar walkthrough |
| `LIVE_REPLAN.md` | The timestamped record of an agent re-planning after an approved goal change |
| `CAPTURE_CONSENT.md` | Consent rules for v1's repo-local session capture |
| `SPRINT_BUILD.md` | Notes from the build sprint |
| `SUBMISSION_CHECKLIST.md` | The hackathon submission checklist |
| `alike/` | Evidence that a fresh agent session retrieved recorded decisions through Alike |

The code as it stood before the retirement is in git history (the parent of the commit that deleted it).
