# server-workspace-admission

Preserve workspace creation, restoration and member limits, access requests and disposable-email refusal.

This is a callable package for the Align native migration. The caller supplies
the resources declared by the [Component](components/server-workspace-admission/component.md) and
selected Node Flavor. Import server_workspace_admission/create_creation, server_workspace_admission/create_access, server_workspace_admission/create_disposable.
