# Home attention

A JavaScript library for the workspace Home's evidence classes, connected-app
status wording and pending change, alignment and launch queues. It exposes nine
natural capabilities without files, network, clock or environment access.

See the [project guide](docs/README.md), [API and availability](docs/user/getting-started.md)
and [qualification queue](docs/roadmap/active-work.md). The accepted specifications
are authoritative. Both clean qualification builds and the admitted build pass.
The parent consumes the verified package through the original typed public names;
its ADOPT-002 queue records complete application parity.
