# Share again wording

Internal wording helpers for Align sessions that ended or stopped sharing. The
library returns the exact structured sentence parts and plain-text instructions
for the session's device and the reader's identity. It performs no I/O.

See [the project guide](docs/README.md) and
[getting started](docs/user/getting-started.md). Reviewed specifications and public
contracts live under `components/share-again`. The independent profile preserves
1,163 source observations in 13 batches. Both clean qualification builds and the
admitted build pass. The parent consumes this verified package through its
original typed public names, with complete application and hosted image gates
recorded in the native rewrite program.
