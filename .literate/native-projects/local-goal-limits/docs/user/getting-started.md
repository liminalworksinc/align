# Getting started

[Project guide](../README.md) > getting started

Use Node24 or later on macOS and Linux. Register this ready child through the
consuming project's native-child plan/apply flow. Materialize its admitted
project-committed cache and import goal_limits/create_goal_limits.
Supply the five resources described by the Node target. The readDate service
returns the current Date constructor for every original global lookup.

Use the pinned runtime:

```console
litai project validate
litai lock components/goal-limits --target goal-limits-host-v1 --check
litai plan components/goal-limits --target goal-limits-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/goal-limits --target goal-limits-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Every reuse requires current independent acceptance. Keep generated source,
qualification and immutable cache records unchanged. Change behavior through the
Component and target, then regenerate. Read
[admitted acceptance](../evidence/admitted-acceptance.json),
[framework flow](framework-flow.md), and [project map](project-layout.md).
