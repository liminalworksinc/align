# Server core and events

This library preserves the complete runtime and public type surfaces of the
existing core and event modules. The Component owns workspace, user, session,
secret, event and effect behavior. The Node target owns exact JavaScript values,
property reads, receivers, callback results, failure propagation and packaging.

`create_core` and `create_events` capture caller-owned ports once. The caller
continues to own database handles, transactions, configuration, identifiers,
cryptography, current host services and delivery infrastructure. Six previously
qualified helper aliases retain their exact provider identities.
