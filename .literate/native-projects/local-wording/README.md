# Wording

A JavaScript library for shared text cleaning, counts, currency and launch or
change-record wording. Its seventeen natural capabilities preserve the original
five modules, including callback order and original thrown objects.

See the [project guide](docs/README.md), [API and availability](docs/user/getting-started.md)
and [qualification queue](docs/roadmap/active-work.md). Both clean qualification builds and the
admitted build pass all 4,598,945 observations in 49 batches. Application
integration and source retirement remain with the parent ADOPT-002 queue.
