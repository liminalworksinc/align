# Agent envelope

Internal formatting and share-state rules for Align sessions. The library builds
goal envelopes and deltas, accepted-ask notes, work cards, request and hold wording,
and share-state notices. Its 49 functions preserve exact strings, caller state and
documented object aliases. Two metadata getters preserve the public constants,
including the shared mutable limit-label record and safe-request Set.

See [the project guide](docs/README.md) and
[getting started](docs/user/getting-started.md). The specification and 51 direct
public contracts live under `components/agent-envelope`. The independent profile
captures 563,717 source observations in 59 batches. Qualification and application
integration are tracked by the parent native rewrite program.
