### Requirement: agent-envelope.latch-way-out

JavaScript module agent_envelope/latch_way_out exports latch_way_out(lid,reshare,reader,release=null,again={}). Synchronous JavaScript library API with no I/O, environment access, clock access, command execution or hidden state. Preserve inputs, their properties and the documented returned aliases. Strings are opaque UTF-16 strings unless a named cleaning operation says otherwise. Do not validate or reject older string values merely because a current TypeScript enum is narrower. Support omitted and undefined optional arguments exactly as their defaults. The only mutable module data is the public LIMIT_WORDS record and SAFE_REQUESTS Set returned by envelope_data; every call observes their current shared objects. Return ordinary JavaScript values without a JSON transport envelope. Release is null or {goals:string[],stopped:boolean}; again has optional unread and login flags. User means reader === user. Id is lid.slice(0,8) verbatim. Run is "{you-run} `align stop-sharing {id}` in a terminal", where you-run is you run for user and the user runs otherwise. Lifted is "after which the stop or hold, if still in place, can be lifted from the web". First, for truthy reshare and again.unread, return "tools stay blocked until it is shared again: {run-or-runs} `align sync` in a terminal first (this machine has not yet heard from the Align server whether its sharing was stopped on the web meanwhile, and one stopped there is not shared again), then {type-or-types} `::align share` in this session, {lifted}.", where run-or-runs is run for user or the user runs otherwise; type-or-types is type for user or types otherwise. Next, for any truthy reshare, return "tools stay blocked until it is shared again ({can-type} `::align share` in this session), {lifted}.", with can-type you can type for user or the user can type otherwise. Next, for truthy again.login, return "tools stay blocked until {run}, or until it is shared again once this machine is signed in ({run-or-runs} `align login` in a terminal, then {type-or-types} `::align share` in this session), {lifted}.", using the same substitutions. Next, for a nonempty release.goals, quote each title in literal double quotes without cleaning or escaping it; join multiple titles as comma-space between all but the last and space-and-space before the last. Hold is the hold on followed by one space and these titles. If release.stopped is truthy, return "tools stay blocked until {run}: the stop can no longer be lifted from the web, and a release of {hold} (which still reaches this session) lifts only the hold.". Otherwise return "tools stay blocked until {hold} is released from the web (a release still reaches this session though its sharing ended), or until {run}.". In all other cases return "tools stay blocked until {run}.". Preserve this precedence and every sentence's exact punctuation.
