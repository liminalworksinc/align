### Requirement: agent-envelope.quoted

JavaScript module agent_envelope/quoted exports quoted(text,max). Synchronous JavaScript library API with no I/O, environment access, clock access, command execution or hidden state. Preserve inputs, their properties and the documented returned aliases. Strings are opaque UTF-16 strings unless a named cleaning operation says otherwise. Do not validate or reject older string values merely because a current TypeScript enum is narrower. Support omitted and undefined optional arguments exactly as their defaults. The only mutable module data is the public LIMIT_WORDS record and SAFE_REQUESTS Set returned by envelope_data; every call observes their current shared objects. Return ordinary JavaScript values without a JSON transport envelope. Return a double quote, clean(text,max) with every double quote changed to an apostrophe, and a final double quote. Backslashes and apostrophes receive no additional escaping.
