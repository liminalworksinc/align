### Requirement: agent-envelope.render-delta

JavaScript module agent_envelope/render_delta exports render_delta(kind,goal,limits=null). Synchronous JavaScript library API with no I/O, environment access, clock access, command execution or hidden state. Preserve inputs, their properties and the documented returned aliases. Strings are opaque UTF-16 strings unless a named cleaning operation says otherwise. Do not validate or reject older string values merely because a current TypeScript enum is narrower. Support omitted and undefined optional arguments exactly as their defaults. The only mutable module data is the public LIMIT_WORDS record and SAFE_REQUESTS Set returned by envelope_data; every call observes their current shared objects. Return ordinary JavaScript values without a JSON transport envelope. For kind exactly unbound or a falsy goal, return "[Align] This session is no longer bound to an Align goal. Continue the user's task as instructed.". Otherwise version is Math.trunc(Number(goal.version)||0) and status is clean(goal.status,20). Suffix is exactly " No added authority.". For bound, prefix is "[Align] From this turn this session counts toward goal \"{title}\" (v{version}, {status})."; otherwise it is "[Align] Goal \"{title}\" is now v{version} ({status}).". When limits is falsy, fit the prefix using clean(goal.title,120), goal measures and suffix as follows. Inline measures read every goal.measures entry when it is an array, or none otherwise, cleaning each text to 80 and ignoring targets. Start with the empty string and append each next item with semicolon-space only when the accumulated string is truthy. Stop before the first candidate exceeding the supplied budget; do not skip it. A fitted note with prefix and suffix reserves room equal to 300 minus (prefix+suffix).length minus the length of " Measures: .". Include inline measures only when that room exceeds 20 and the resulting inline string is truthy, as prefix followed by " Measures: ", inline, one period, and suffix. Otherwise use prefix+suffix. Take the first 300 units when necessary. For a truthy limits object, its added and removed arrays supply a limit note. If added is nonempty, use its first entry: the line is Limit: for bound, otherwise New limit:, followed by one space, current LIMIT_WORDS[type] ?? Must, another space, and quoted(text,limitMax). Apply end_sentence to the entire line, then append " (+{added.length-1} more, listed below.)" only when more than one was added. If removed is nonempty, the line is Limit removed: followed by one space and quoted(first.text,Math.min(80,limitMax)); apply end_sentence, then append " (+{removed.length-1} more removed.)" only when more than one was removed. Join the nonempty added/removed lines with one space. Try [titleMax,limitMax] tuples [120,120],[60,120],[60,80],[40,50]. Candidate is prefix(clean(title,titleMax)), one space, limit note, then suffix. Return the first candidate of at most 300 units. A truthy limits object with empty arrays retains the resulting double space before No added authority. If none fits, build the candidate with titleMax 40 and limitMax 30 and take its first 300 units.
