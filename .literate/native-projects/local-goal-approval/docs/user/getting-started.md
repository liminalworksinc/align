# Getting started

[Project guide](../README.md) > getting started

This dependency-free CommonJS library requires Node24 or later on macOS and Linux.
Register the ready child through the consuming project's native-child plan/apply
flow. Materialize the admitted project-committed cache and import
goal_approval/create_approval. Supply the one all service described by the Node
target. Keep authenticated facts, storage and decision/launch writes in callers.

Use the pinned runtime:

```console
litai project validate
litai lock components/goal-approval --target goal-approval-host-v1 --check
litai plan components/goal-approval --target goal-approval-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/goal-approval --target goal-approval-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Every cache reuse requires current independent acceptance. Keep generated source,
qualification and immutable cache records unchanged. Change behavior through the
Component and Node target, then regenerate. Read
[admitted acceptance](../evidence/admitted-acceptance.json),
[framework flow](framework-flow.md), and [project map](project-layout.md).
