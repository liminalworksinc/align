### Requirement: agent-envelope.render-card

JavaScript module agent_envelope/render_card exports render_card(sibs). Synchronous JavaScript library API with no I/O, environment access, clock access, command execution or hidden state. Preserve inputs, their properties and the documented returned aliases. Strings are opaque UTF-16 strings unless a named cleaning operation says otherwise. Do not validate or reject older string values merely because a current TypeScript enum is narrower. Support omitted and undefined optional arguments exactly as their defaults. The only mutable module data is the public LIMIT_WORDS record and SAFE_REQUESTS Set returned by envelope_data; every call observes their current shared objects. Return ordinary JavaScript values without a JSON transport envelope. Return null for an empty list. A sibling has harness,id,minutes_ago,files,commits and optional who,remote,overlap,task,goal,unnamed,sessions,claims. Group falsy-remote locals and truthy-remote others separately, preserving order within each. Locals come first unless both groups exist and the first input is remote. Local heading/tail are "Also working toward this goal on this machine:" and "Read their changes before editing the same files.". Remote heading/tail are "In flight toward this goal and related ones:" and TEAM_POINTER. A sibling line with maxFiles and detail has name "{person_name(who)} ({sessions} session{s}, {ago})" for remote, where sessions = s.sessions ?? 1 and plural s only when sessions > 1. A local name is "{harness-label} session {short_id(harness,id)} (active {ago})". Harness-label is Codex only for exact codex, otherwise Claude Code. Ago is just now for minutes_ago < 1, otherwise {minutes_ago} min ago. Select overlap from (s.overlap || []).slice(0,Math.max(1,maxFiles)) and clean each to 60. Overlap is the caller's local overlap data, so use clean even for remote. Filter original s.files to exclude every value contained in the entire original overlap list, take at most Math.max(0,maxFiles-selectedOverlap.length), then use remote_path for remote and clean(file,60) for local. More = original files.length minus selected files.length minus selected overlap.length plus (unnamed || 0). Build ordered parts. At detail >= 1 with truthy goal, add "toward \"{clean(goal,60)}\"". At detail >= 1 with truthy task for local only, add "on \"{clean(task,50)}\"". Named files are the selected overlap entries with " (yours too)" appended, then selected files. When any exist, add edited followed by one space and that list joined with comma-space, plus " and {more} more" for more > 0. Without names but more > 0 add edited {more} file{s}, plural only for more > 1. At detail >= 1 with claims, add claimed followed by one space and the first two claims through the same remote/local path cleaner, joined with comma-space. At detail >= 2 with any commits, for local only add "committed \"{clean(first-commit,60)}\"". Join parts with semicolon-space. The line is name plus colon-space and parts only when any exist, then one period. Never show remote task text or commit subjects. A group part joins its heading, the kept sibling lines, an optional "Also {senders_words(remaining,more-space)}." when siblings remain, and its tail with single spaces. The first shown sibling of the first group uses at least detail 1; every other sibling uses the candidate detail. More-space is the literal more followed by a space. Cap is 300 for one group, 450 for two. Cap each group's shown count at min(length,3). Enumerate keep splits by descending total shown from the sum of caps down to group count; for each total, first-group count descends from min(firstCap,total-(groupCount-1)) to one. A one-group split is valid only when it uses that total; a two-group split must leave second count between one and secondCap. First try all candidates with a minimum of one file per sibling, then with minimum zero. Within each minimum, traverse keep splits in that order, detail 2,1,0, then maxFiles 3,2,1,0 restricted to values at least the minimum. Join [Align] and all group parts with single spaces; return the first text within cap. If no candidate fits, use [Align], first heading, senders_words(all first-group siblings) plus period, and first tail. Append the second group's heading, count phrase plus period and tail when present, all separated with single spaces. Take the first cap units.
