# Public interface: agent-envelope.request-notice

## ADDED Requirements

### Requirement: agent-envelope.request-notice

JavaScript module agent_envelope/request_notice exports request_notice(r). Synchronous JavaScript library API with no I/O, environment access, clock access, command execution or hidden state. Preserve inputs, their properties and the documented returned aliases. Strings are opaque UTF-16 strings unless a named cleaning operation says otherwise. Do not validate or reject older string values merely because a current TypeScript enum is narrower. Support omitted and undefined optional arguments exactly as their defaults. The only mutable module data is the public LIMIT_WORDS record and SAFE_REQUESTS Set returned by envelope_data; every call observes their current shared objects. Return ordinary JavaScript values without a JSON transport envelope. A request has id,type,optional sender{name,role},optional goal{id,title,version},optional target_goal{title},optional note and cancel_reason. Sender is clean(sender?.name,50) || Someone. Goal and target titles are clean of their optional title to 100. Note is quoted(note,280) only when the original note is truthy, otherwise absent. A goal version is Math.trunc(Number(goal?.version)||0). Type and role comparisons are exact and case-sensitive. Role is workspace owner only when sender?.role is exactly owner; otherwise "approver of \"{goal-title}\"". Ask for switch_goal is "move this session from goal \"{goal-title}\" to goal \"{target-title}\". Nothing changes unless you accept". For checkpoint it is "at the end of the current step, commit the work and summarize where things stand. It goes to the agent now as a safe step that needs no answer. Align reports it delivered to the agent and not declined (not that the agent did it) until you decline it, which you can do now or later". Otherwise it is "re-read goal \"{goal-title}\" (v{version}) and update the plan. The agent is asked to draft an updated plan for you and to keep its current course until you agree. It goes to the agent now: drafting the plan needs no answer from you, and the plan changes only when you accept it. Align reports it delivered to the agent and not declined (not that the agent did it) until you decline it, which you can do now or later". Answer for checkpoint is "Run `::align decline {short-id}` if you don't want it, or tell the agent."; for exact replan it is "Run `::align accept {short-id}` when you agree to its plan, or `::align decline {short-id}`, or tell the agent."; otherwise "Run `::align accept {short-id}` or `::align decline {short-id}`, or tell the agent.". Short-id is request_short_id(r.id). Return "Align: {sender} ({role}) asks: {ask}.{optional-note} {answer}", where optional-note is " Note: {note}." when note is present, otherwise empty. Preserve punctuation even when source fields already end in punctuation.
