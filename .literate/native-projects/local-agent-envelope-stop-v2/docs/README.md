# Agent Envelope guide

Agent Envelope defines the session context and sharing notices used by Align's
local agent. It preserves workspace stops after sharing ends or shared history
is deleted, while keeping goal hold release rules separate.

Read [getting started](user/getting-started.md) for current availability and the
contributor workflow. The Component at `components/agent-envelope/component.md`
and its public interface contracts define behavior. The
[framework flow](user/framework-flow.md) explains generation and verification.

Contributor references include [active work](roadmap/active-work.md),
[the project map](user/project-layout.md),
[readable specifications](user/specifications.md),
[models and generation](user/models-and-generation.md),
[private test matrices](user/test-matrix.md), and [security](user/security.md).
Read [skill boundaries](architecture/skills.md),
[the authority learning loop](architecture/authority-learning-loop.md),
[the mission specification map](architecture/mission-specification-composition.md),
and [design traceability](architecture/design-traceability.md) when changing
