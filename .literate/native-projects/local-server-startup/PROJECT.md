# Server startup

This project owns the bound startup operation used by Align. The Component
preserves startup admission, PID ownership checks, leftover cleanup, warnings
and exit cleanup. The Node Flavor binds 19 caller-owned validation, process,
configuration, filesystem, path and warning functions.

The factory `create_startup(context)` returns `startup(): void`. Configuration
validation, OAuth directory derivation, readiness and instrumentation's later
database, owner and retention sequence retain their existing owners.
