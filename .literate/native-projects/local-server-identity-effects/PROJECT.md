# Sign-in delivery and configured verification

This library preserves the complete mail and captcha helper surfaces. The
Component owns delivery content, effect ordering, verification decisions and
failure propagation. Its Node target owns exact JavaScript values, resource
capture, live host resolvers, receivers and the dependency-free package layout.

`create_effects` captures 15 caller-owned resources without invoking them. It
exposes five operations and two constants. The host retains configuration,
delivery, filesystem, captcha provider and the existing public error class.
