# Authentication configuration and sign-in lifecycle

This library preserves authentication configuration, session caps, email-code
admission and delivery failure handling, passkey callbacks, shared instance
reuse and migration orchestration. The Component owns observable behavior.
The Node target owns the exact adapter representation and 52 caller-supplied
resource bindings. Persistence, delivery, configuration and provider mechanisms
remain with the caller.
