# Getting started

[Project guide](../README.md) > getting started

Use Node24 or later on macOS and Linux. Register the ready child normally,
materialize its admitted committed cache and import
server_change_read/create_records. Supply the four resources in the Node target.
Pass the caller's exact V2Error constructor. Preserve the six public types and
compile-time state equality check at the caller boundary.

```console
litai project validate
litai lock components/server-change-read --target server-change-read-host-v1 --check
litai plan components/server-change-read --target server-change-read-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/server-change-read --target server-change-read-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Each reuse requires current independent acceptance. Change intent in the
Component and target, then regenerate. Preserve source, qualification and cache
records. Read [admitted acceptance](../evidence/admitted-acceptance.json),
[framework flow](framework-flow.md), and [project map](project-layout.md).
