Serve workspace feeds, usage, allocation, value and reporting through the existing permissions.

This is a callable package for the Align native migration. The caller supplies
the resources declared by the [Component](components/server-workspace-reporting-routes/component.md) and
selected Node Flavor. Import server_workspace_reporting_routes/create_workspace_reporting_routes.
