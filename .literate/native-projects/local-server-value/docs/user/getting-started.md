# Getting started

[Project guide](../README.md) > getting started

Use Node24 or later on macOS and Linux. Register the ready child through the
normal native-child plan/apply flow, materialize its admitted committed cache,
and import server_value/create_value. Supply the26 resources described by the
Node target. readDate returns the current Date constructor at each original
lookup. Keep caller types and re-exports at the existing boundary.

```console
litai project validate
litai lock components/server-value --target server-value-host-v1 --check
litai plan components/server-value --target server-value-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/server-value --target server-value-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Every reuse requires current independent acceptance. Preserve generated files,
qualification and immutable cache records. Change intent through the Component
and target, then regenerate. Read
[admitted acceptance](../evidence/admitted-acceptance.json),
[framework flow](framework-flow.md), and [project map](project-layout.md).
