# server-core

Enforce own event names and preflight every device-request JSON value before purge writes, with exact actual-caller types including nullable soft-delete actors.

This is a callable package for the Align native migration. The caller supplies
the resources declared by the [Component](components/server-core/component.md) and
selected Node Flavor. Import server_core/create_core, server_core/create_events.

[acceptance contract](verification/acceptance/server-core.json),
[local evidence](docs/evidence/admitted-acceptance.json), and
[active work](docs/roadmap/active-work.md).
