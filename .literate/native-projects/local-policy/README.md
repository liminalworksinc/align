# Policy

Internal authorization library for Align. It provides authorization decisions,
goal readability and binding helpers, and the six policy data values. The public
contract preserves the existing JavaScript Map and object API.

The component specification and public contracts are in `components/policy`.
The independent profile covers 331,937 reference observations in 43 batches.
Regenerative qualification is required for specification release authority.
Application integration and its complete sealed receipt are separate gates.

See `docs/README.md` and `docs/user/getting-started.md` for contributor guidance.
