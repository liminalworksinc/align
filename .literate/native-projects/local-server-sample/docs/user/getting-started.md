# Getting started

[Project guide](../README.md) > getting started

This CommonJS library requires Node 24 or later on macOS and Linux.

## Installation and usage

Register this ready child through the consuming project's native-child plan/apply
flow. Materialize the admitted project-committed cache and its exact asset.
Import create_sample from server_sample/create_sample and supply all ten
resources in the Node target. Workspace creation, storage and goal services are
caller-owned. Preserve the ordinary immutable asset beside the generated module.
The root README links the Component, target and independent acceptance.

## Contributor workflow

Use the pinned runtime and configured provider:

```console
litai project validate
litai lock components/server-sample --target server-sample-host-v1 --check
litai plan components/server-sample --target server-sample-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/server-sample --target server-sample-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Every cache reuse requires current independent acceptance. Keep generated code,
qualification, immutable asset and cache records unchanged. Change behavior
through the Component and Node target, then regenerate. Qualification requires
the exact original source retained separately by the consuming project.
Read [admitted acceptance](../evidence/admitted-acceptance.json),
the [framework flow](framework-flow.md), and [project map](project-layout.md).
