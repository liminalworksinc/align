Preserve the explicitly labeled sample workspace, its ordinary creation gate,
ordered seed, shared anchors and exact transactional failure behavior.

Read the [project record](PROJECT.md), [project guide](docs/README.md),
[Component](components/server-sample/component.md),
[Node target](flavors/node-server-sample/flavor.md), and
[independent acceptance](verification/acceptance/server-sample.json).

The CommonJS server_sample package exposes create_sample from
server_sample/create_sample. Supply all ten declared resources. It returns three
string constants and the asynchronous createSampleWorkspace function. The
ordinary immutable sample-text asset supplies the exact fictional sample text.
