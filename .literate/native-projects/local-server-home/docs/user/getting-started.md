# Getting started

[Project guide](../README.md) > getting started

Use Node 24 or 26 on macOS and Linux, within the selected Flavor's supported range. Register the ready child through the
normal native-child plan/apply flow, materialize its admitted committed cache
and import server_home/create_home. Supply the 14 resources in the Node target
and retain the 7 public types at the original caller boundary. Preserve
live arrays and the original method signatures, defaults and asynchronous kinds.

```console
litai project validate
litai lock components/server-home --target server-home-host-v1 --check
litai plan components/server-home --target server-home-host-v1
litai verify
```

After execution authorization:

```console
litai rebuild components/server-home --target server-home-host-v1 --allow-host-execution --update-receipt
litai project test-receipt require-current --project .
litai cache publish --project . --target project-committed
```

Every reuse requires current independent acceptance. Change intent through the
Component and target, then regenerate. Preserve generated files, qualifications
and immutable cache records. Read
[admitted acceptance](../evidence/admitted-acceptance.json),
[framework flow](framework-flow.md), and [project map](project-layout.md).
