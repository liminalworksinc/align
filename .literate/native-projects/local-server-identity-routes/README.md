# server-identity-routes

Preserve identity, device pairing, sign-in, invitations and workspace-creation HTTP routes.

This is a callable package for the Align native migration. The caller supplies
the resources declared by the [Component](components/server-identity-routes/component.md) and
selected Node Flavor. Import server_identity_routes/create_identity_routes.

[local evidence](docs/evidence/admitted-acceptance.json), and
