# server-sessions-directives-routes

Preserve session, request, hold, release and directive HTTP routes and their device ownership checks.

This is a callable package for the Align native migration. The caller supplies
the resources declared by the [Component](components/server-sessions-directives-routes/component.md) and
selected Node Flavor. Import server_sessions_directives_routes/create_sessions_directives_routes.
