# Value-card rules

Seven synchronous APIs preserve estimate wording, value-note cleaning, safe follow-up
links and measured-span wording. A metadata getter retains the shared mutable
estimate table and three constants. Two APIs use the current named environment
fields only when their environment argument is omitted or undefined.

See the [project guide](docs/README.md), [API and availability](docs/user/getting-started.md)
and [qualification queue](docs/roadmap/active-work.md). Two clean qualification builds and the admitted build pass all 1,168,597
observations in 16 batches. Parent application integration remains pending.
