# Share notices

Internal notice helpers for Align sessions. The library extracts notice kinds,
recognizes share-state prefixes and preserves the exact resumed/held wording.
Its public mutable prefix array remains shared with the matching function.

See [the project guide](docs/README.md) and
[getting started](docs/user/getting-started.md). The specification and direct
public contracts live under `components/share-notices`. The independent profile
captures 1,099 source observations in 14 batches. Qualification and application
integration are tracked in the parent native rewrite program.
