# Field validation

One synchronous factory supplies fifteen field validators and six shared data
exports. It receives the existing wording functions and error factory explicitly,
preserving the caller's error identity, Unicode behavior and mutable regular
expressions. It needs no credentials, network, filesystem or current time.

Read the [project guide](docs/README.md), [API](docs/user/getting-started.md) and
[qualification record](docs/roadmap/active-work.md). Both clean qualification
builds and a separate admitted build pass. Parent consumer integration remains
separate.
