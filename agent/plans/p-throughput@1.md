# Team triage plan p-throughput v1

Source: Security goal v1, "Maintain high-quality incident triage across platform services."
Measure: tickets triaged per day, oldest first (throughput).

- Work the open queue oldest first and triage as many tickets as you can.
- For each ticket: keep its existing tags and add the tag `triaged`; set priority by apparent severity (low, normal, high or urgent).
- Add one public reply to each ticket acknowledging the request and saying the team is on it.
- Routine questions and simple requests may be marked solved after your reply.
