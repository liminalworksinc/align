# LIM-2455 v2 acceptance checklist: audit against the v2 branch

The founder's checklist (`LIM-2455.checklist.md`, PR #39, written against `02f0e1f`) audited item by item against this
branch (`port-44-39`, based on `db2be8c`). The checklist's line cites are stale; the cites below are current. Paths are
relative to `components/legacy-project-wrapper/implementation/` unless they start with `specs/`. Tests are named by the
start of their `check(...)` title in `scripts/test-v2.mjs` (v2) or `scripts/test-oauth.mjs` (oauth).

Status: **pass** (true on the base commit; a test may have been added to prove it), **fixed** (changed here, with spec
and test), **open** (needs a founder ruling or a manual step), or **owned by Lane C/B port** (the change-request
decision panel and the Home's first-run area, which another agent is rebuilding; not edited here).

D1 (launch) and D2 ("Accept if…" conditions) were built before this audit and are not re-audited.
